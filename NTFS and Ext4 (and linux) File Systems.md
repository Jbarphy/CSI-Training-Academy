Directories in linux are normally contained with the following structure:
* /bin: common commands
* /boot: files needed at boot, such as kernel images used by LILO or GRUB
* /dev: files that represent drives (device nodes)
* /etc: Administrative configurations files and scripts
* /home: Use home directory with personal files plus specific config files
* /lib: 32 bit software library
* /lib64: 64 bit software library
* /media: standard place system for media
* /mnt: temp place for mounting
* /opt: external software like chrome install location
* /run: dynamic run time files for system daemons like eudev and udisk or other external volumes mounted
* /sbin: Administrative and system commands
* /usr: contains locals software, libraries, games, etc.
* /var: Logs and other variable files
